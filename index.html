What is the Partition Problem?

Given a multiset S = {a₁, a₂, a₃ ... aₙ}, determine whether it can be partitioned into two subsets S₁ and S₂ such that the sum of elements in S₁ equals the sum in S₂.
sum(S₁) = sum(S₂) = total / 2

Step 1 — Proving Partition is in NP

Certificate

A proposed partition, e.g., S₁ = {11}, S₂ = {1,5,5}.

Verifier

Calculate sum(S₁) and sum(S₂) and check if they are equal. O(n) time.
Time Complexity = O(n)
Therefore, Partition Problem ∈ NP

Step 2 — Reduction from Subset Sum

We transform any Subset Sum instance into a Partition instance in polynomial time.
x = A - 2T
S'' = S ∪ {x}
Original Subset Sum has solution ⇔ New Partition instance has solution.

Forward Direction Proof

If the original Subset Sum instance has a solution, then the constructed Partition instance also has a solution.
Subset Sum YES → Partition YES

Backward Direction Proof

If the constructed Partition instance has a solution, then the original Subset Sum instance also has a solution.
Partition YES → Subset Sum YES

Polynomial-Time Construction

The reduction only requires:

- Calculating the sum of all numbers
- Computing x
- Adding one extra number
Complexity = O(n)
